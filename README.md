# Win11 Лаунчер для Android TV

Сверхлёгкий лаунчер (Kotlin, без сторонних библиотек). Режимы: ТВ (по умолчанию) и Windows 11.

## Сборка без Android Studio
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку Actions -> «Build APK» -> Run workflow (или просто сделайте push).
3. Скачайте артефакт `Win11Launcher-apk` (внутри app-release.apk и app-debug.apk).
4. Установите APK на ТВ и нажмите Домой -> «Всегда» для лаунчера Win11.

## Управление
- OK (коротко) — открыть, OK (долго) — меню ярлыка; на плитке «Добавить» — список приложений.
- Меню (коротко) — Пуск / настройки, Меню (долго) — вкл/выкл виртуальный курсор.
- Кнопка INPUT на пульте (если есть) открывает окно «Входы (HDMI)».
